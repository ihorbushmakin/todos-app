# Simple Todos App

Ein einfacher, übersichtlicher Aufgabenmanager mit Django und Bootstrap erstellt.

## Funktionen

- Benutzerregistrierung / Anmeldung / Abmeldung  
- Aufgaben erstellen / bearbeiten / löschen  
- Aufgaben als erledigt markieren  
- Aufgabenbeschreibung mit sanfter Umschaltung  
- Bootstrap-5-Oberfläche  
- Hinweise für Nutzerfeedback  
- Vollständig authentifizierte Ansichten  

## Technologien

- Django 4.x  
- Python 3.x  
- Bootstrap 5  

## Einrichtung

```bash
git clone ...
cd ...
python -m venv .venv
source .venv/bin/activate  # oder .venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
